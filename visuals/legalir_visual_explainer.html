  • Viết baseline BM25

A. Tách từ và chuẩn hóa text

Code biến câu hỏi và passage thành những token có thể so sánh được. Bỏ dấu giúp câu hỏi tiếng Việt khớp với title/link dạng không dấu.

def tokens(text, fold_accents, remove_stopwords):
    value = fold(text) if fold_accents else text.lower()
    values = TOKEN_RE.findall(value)
    return [word for word in values
            if word not in stopwords]

File: src/legalir_baseline.py

B. Tạo BM25 index

Code đọc 8.532 passage một lần, đếm token và lưu chúng vào index. Nhờ vậy không cần đọc lại toàn bộ file cho từng câu hỏi.

for doc_index, item in enumerate(corpus):
    text = item["passage"]
    text = item["name"] + " " + text
    counts = Counter(tokens(text, ...))
    postings[term].append((doc_index, tf))

Ý nghĩa: biến corpus thành “mục lục tìm kiếm”.

C. Xếp hạng và lấy top 5

Mỗi từ trong câu hỏi đóng góp một điểm. Document chứa các từ hiếm và khớp tốt sẽ được điểm BM25 cao hơn.

scores[doc_index] += idf * (
    term_frequency * (k1 + 1) / denominator
)

ranked = top_5_documents(scores)
return document_ids(ranked)

Output: chỉ là ID dự đoán, không phải đáp án BTC.

D. Đo và kiểm tra

Với train/dev có nhãn, code so prediction với gold ID. Với Public, chỉ validator chạy được vì gold answer bị giấu.

relevant = gold_ids & predicted_ids
recall = len(relevant) / len(gold_ids)
precision = len(relevant) / len(predicted_ids)
