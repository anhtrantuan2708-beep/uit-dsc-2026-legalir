1. Competition yêu cầu gì?

Input

Câu hỏi pháp luật bằng tiếng Việt, gắn với một question_id.

Output

Một câu trả lời văn xuôi bằng tiếng Việt cho mỗi câu hỏi.

Đánh giá

So sánh với câu trả lời tham chiếu của chuyên gia pháp lý bằng METEOR và ROUGE-L.

Submission format

submission.zip └── submission.json { "147194": { "answer": "Theo quy định tại Điều 37..." } }

ZIP chỉ được chứa đúng một file submission.json. Mỗi question_id xuất hiện đúng một lần; answer phải là string UTF-8.

4. Quy tắc thử nghiệm

Không submit ngẫu nhiên

Mỗi thử nghiệm phải có hypothesis, owner, config, local score và experiment ID.

Leaderboard chỉ là tín hiệu

Không overfit theo một lần public score. Phải xem cả error analysis và local validation.

Mọi thứ phải tái lập

Lưu commit, seed, prompt, model metadata, ZIP và checksum.
