# Glossary cho người mới

| Từ | Nghĩa đơn giản |
|---|---|
| Dataset | Tập dữ liệu dùng cho cuộc thi |
| Sample/row | Một mẫu dữ liệu |
| ID | Mã định danh của mẫu hoặc văn bản |
| Query/question | Câu hỏi đầu vào |
| Corpus/context | Kho nội dung để hệ thống đọc và tìm kiếm |
| Document | Một văn bản trong corpus |
| Label | Nhãn cần dự đoán |
| Prediction | Dự đoán của model |
| Ground truth | Đáp án đúng do BTC giữ |
| Train set | Dữ liệu dùng để phát triển phương pháp |
| Validation set | Dữ liệu tự giữ lại để kiểm tra trước khi submit |
| Test set | Dữ liệu BTC dùng để chấm |
| Baseline | Cách làm đơn giản đầu tiên để có mốc so sánh |
| Retrieval | Tìm các văn bản liên quan |
| BM25 | Cách xếp hạng văn bản dựa trên từ khóa |
| Embedding | Biểu diễn câu/văn bản thành vector để tìm theo nghĩa |
| Reranker | Model đọc kỹ và sắp xếp lại kết quả |
| Recall | Tỷ lệ đáp án đúng đã tìm thấy |
| Precision | Tỷ lệ kết quả trả về là đúng |
| F1 | Điểm cân bằng giữa Precision và Recall |
| Macro-F1 | Trung bình F1 của các nhãn, mỗi nhãn có trọng số ngang nhau |
| Hallucination | Model nói điều không được hỗ trợ hoặc nói sai context |
| Submission | File gửi lên Codabench |
| Leaderboard | Bảng xếp hạng |
