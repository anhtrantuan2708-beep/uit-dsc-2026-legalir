# Checklist thực hành warmup

## Buổi 1 — 45 phút

- [ ] Đọc `docs/00_beginner_overview.md`.
- [ ] Đọc `docs/01_glossary_for_newbie.md`.
- [ ] Mở `data/raw/warmup.json`.
- [ ] Viết lại bằng lời của mình: input là gì, output là gì.

## Buổi 2 — 60 phút

- [ ] Đếm số query.
- [ ] In một query.
- [ ] Tạo một output giả.
- [ ] Kiểm tra JSON hợp lệ.

## Buổi 3 — 60 phút

- [ ] Xác định task thật từ BTC.
- [ ] Chọn đúng walkthrough: LegalIR hoặc hallucination.
- [ ] Viết baseline đầu tiên.

## Definition of done cho warmup

Warmup được xem là hoàn thành khi bạn có thể tự giải thích:

1. Input là gì?
2. Output là gì?
3. Một mẫu dữ liệu gồm những field nào?
4. Metric nào dùng để chấm?
5. File nộp phải có cấu trúc gì?
